# 👑 Golden Machine — FunPay Automation Suite MVP

> **Golden Machine** — Профессиональный программный комплекс для полной автоматизации работы с торговой площадкой **FunPay**.
> Включает умный генератор уникальных названий (80,000+ комбинаций), автоперевод на английский язык, автовыдачу заказов, авто-поднятие лотов и роскошный локальный Web Dashboard.

## 🌟 Ключевые возможности

- 🖥 **Красивый 1-Click Лаунчер**: Запуск одной кнопкой через `launcher.bat` с автоматической установкой модулей, стартом сервера и открытием браузера.
- 🔑 **Подключение через Golden Key**: Быстрая и безопасная авторизация по сессионному токену FunPay.
- 📦 **Большая актуальная база лотов**: Встроенные готовые лоты по топовым играм (CS2, Dota 2, Valorant, GTA 5 / RP, Rust, Genshin Impact, Tarkov, Minecraft, Roblox, Steam, Telegram).
- 📑 **3 Автоматических шаблона лотов**:
  - **Шаблон 1 (Гайды на разные игры)**: Пошаговые мануалы, конфиги, раскидки, секреты и оптимизация.
  - **Шаблон 2 (Бустеры / Обучение)**: Услуги коучинга, калибровки, разбора демок и тренировок.
  - **Шаблон 3 (Свободный шаблон)**: Произвольные цифровые товары, ключи, смена региона и кастомные позиции.
- 🎲 **Генератор вариативности (80,000+ названий)**:
  - Комбинаторика префиксов, синонимов, эмодзи, тегов и гарантий.
  - Анти-дубликация и обход фильтров площадки.
  - Поддержка Spintax-шаблонов `{вариант 1|вариант 2|вариант 3}`.
- 🌐 **Автоматический перевод на английский**:
  - Мгновенный перевод названий и описаний для иностранной аудитории.
  - Режим двуязычной публикации (`RU + EN`).
- 💬 **Авто-выдача покупателю после покупки**:
  - Мгновенная доставка инструкций, ссылок или ключей в чат заказа сразу после оплаты.
- ⚡ **Автоподнятие лотов (Auto-Bump)**:
  - Фоновый таймер периодического авто-поднятия лотов в топ каталога.
- 🛡️ **Анти-бан Safe Mode**:
  - Рандомизированные задержки между выставлениями лотов (15-45 сек).

## 🚀 Быстрый старт

### Вариант 1: Через лаунчер (Windows)
Просто дважды кликните по файлу **`launcher.bat`** в папке проекта. Лаунчер автоматически:
1. Проверит и установит зависимости (`npm install`).
2. Запустит ядро Golden Machine.
3. Откроет веб-панель управления в вашем браузере по адресу `http://localhost:3000`.

### Вариант 2: Через консоль
```bash
# Установка зависимостей
npm install

# Запуск сервера
npm start
```

После запуска перейдите в браузере по адресу: [http://localhost:3000](http://localhost:3000)

## 🔑 Как получить токен `golden_key` на FunPay

1. Перейдите на сайт [FunPay.com](https://funpay.com) и войдите в свой аккаунт.
2. Нажмите клавишу `F12` (или `Ctrl + Shift + I`), чтобы открыть панель разработчика.
3. Перейдите на вкладку **Application** (или **Хранилище** в Firefox) -> раздел **Cookies** -> `https://funpay.com`.
4. Найдите строку с именем **`golden_key`** и скопируйте её 32-значное значение.
5. Вставьте токен в панели Golden Machine на вкладке **«FunPay Аккаунт»** и нажмите **«Сохранить и проверить»**.
